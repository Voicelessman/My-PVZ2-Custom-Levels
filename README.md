# My-PVZ2-Custom-Levels
This repository includes all of my custom PVZ2 levels made with PVSZ2 (Link: https://pvsz2.ru/level-editor)

HOW TO INSTALL:
1. Download one of the RTON files
2. Insert them into this path: My files/Play Files/Android/data/com.ea.game.pvz2_na/files/No_Backup/CDN.x.x (Version)/levels (If you don't see the Android folder, toggle "Show all play folders" or "Show hidden folders")
3. Play the game and enjoy!

NOTE:
Make sure you have NO premium or seedium plants unlocked when you play these levels as you unlock some in some.
Do not change the file name or it will not work.
Do not put two levels with the same file name together as one will replace the other.
